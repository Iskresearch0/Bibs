Hayku is a personal AI language model project developed by Isk for learning, experimentation, and independent research in artificial intelligence.

The project aims to build a language model from scratch using Python and the standard Transformer architecture, with a focus on understanding the fundamentals of model architecture, dataset preparation, and language model training.

Overview

* Project: Hayku
* Model: Hayku 0.1
* Creator: Isk
* Language: Python
* Architecture: Transformer
* Initial target: 20 million parameters (20M)
* Long-term goal: Explore scaling the model toward 1 billion parameters (1B)
* Training approach: From scratch
* Dataset: Custom-built dataset using refined data sourced from Hugging Face
* Purpose: Personal study and experimentation

Project Goals

Hayku is an educational project designed to explore the process of creating and training a language model from the ground up.

The main goals are:

* Implement a Transformer-based language model in Python.
* Build a custom dataset from carefully selected and refined data sources available through Hugging Face.
* Develop a training pipeline for learning from scratch.
* Experiment with tokenization, model configuration, and optimization.
* Evaluate model behavior, training performance, and generated text.
* Establish a foundation that could support future experiments with larger models.

Model Specifications

Hayku 0.1 — Initial Version

The first version targets approximately 20 million parameters (20M).

This relatively small model will serve as the initial experimental baseline, allowing the architecture, dataset, and training process to be tested before attempting larger configurations.

The initial focus is on building a functional model and understanding its capabilities and limitations.

Future Development

The long-term ambition is to investigate scaling Hayku toward 1 billion parameters (1B).

This is a future goal, not a guarantee. Progress toward that scale will depend on experimental results, dataset quality, available hardware, memory requirements, and training costs.

Architecture

Hayku will use the standard Transformer architecture, implemented in Python.

The project will investigate the essential components of a language model, including:

* Token embeddings
* Positional information
* Self-attention mechanisms
* Feed-forward networks
* Transformer blocks
* Language modeling output layer
* Training and inference procedures

The implementation and configuration may evolve as the project develops.

Dataset

Hayku will use a custom dataset built from scratch using carefully selected, refined, and compatible data sourced from Hugging Face.

The objective is to prioritize data quality, consistency, and usefulness rather than simply collecting large quantities of unfiltered text.

Dataset preparation may include:

* Selecting appropriate source datasets.
* Cleaning and normalizing text.
* Removing duplicates and unsuitable content.
* Checking data quality and compatibility.
* Preparing text for tokenization and training.
* Maintaining awareness of dataset licenses and usage restrictions.

The dataset will be developed specifically for the project’s training objectives.

Training

The initial model is intended to be trained from scratch, rather than starting from the pretrained weights of an existing language model.

The training workflow will focus on:

1. Preparing and validating the dataset.
2. Training or configuring a tokenizer.
3. Initializing the Transformer model.
4. Training the model on the prepared data.
5. Monitoring training metrics and model behavior.
6. Evaluating the resulting model.
7. Saving checkpoints and model artifacts for future experiments.

Training configurations and implementation details may change as the project progresses.

Project Status

Hayku 0.1 is an experimental personal project. Its implementation, training pipeline, dataset, and evaluation process will be developed and refined over time.

The initial milestone is to establish a working 20M-parameter model trained from scratch. Larger models will be considered after the initial experiments provide useful results.

Intended Use

Hayku is intended exclusively for personal study, experimentation, and learning about AI and language model development.

It is not presented as a production-ready AI system or as a replacement for larger pretrained language models.
